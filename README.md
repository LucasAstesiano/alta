# ALTA Trail Lab

Sitio de marca para ALTA Trail Lab, inspirado en el trail running patagónico y
en una paleta mineral de carbón, niebla y naranja.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) para ver el sitio.

## Validación y producción

```bash
npm run lint
npm run build
npm run start
```

La página de inicio está en `src/app/page.tsx`; estilos globales en
`src/app/globals.css`. Las fotografías de referencia se sirven desde Unsplash.
